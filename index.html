    ¿Qué es una skill en AgentHub?

    Una skill es una capacidad modular y facturable que se acopla a un agente para habilitar una tarea concreta —consultar una base de datos, redactar informes, analizar imágenes o integrarse con un servicio externo—. Cada agente puede combinar varias skills, y su precio se imputa de forma individual en el contrato de alquiler.
